# Plan for corepost-mobile-ios

## Роль репозитория

iOS panic-клиент на Swift, функционально эквивалентный Android-приложению.

## Текущее состояние

- Репозиторий создан заново, кодовой базы пока нет.
- На хосте уже есть Xcode 16.4 и Swift 6.1.2, значит можно сразу закладывать реальную сборку и архивирование.

## Что сделать

- Создать Xcode-проект и выбрать стек:
  - предпочтительно SwiftUI + async/await;
  - минимальная поддерживаемая версия iOS согласуется с доступным SDK.
- Реализовать те же сценарии, что и на Android:
  - настройка подключения;
  - проверка статуса;
  - lock/unlock;
  - двухшаговое подтверждение;
  - обработка сетевых ошибок.
- Согласовать с сервером модель секретов и заголовков HMAC.
- Хранить конфиг и секреты в Keychain.
- Настроить TLS и обработку сертификатов.
- Добавить базовые unit/UI tests.
- Подготовить release pipeline:
  - version/build numbers;
  - archive через `xcodebuild`;
  - экспорт `.ipa`;
  - release notes и публикация в GitHub Releases.
- Привести branding и тексты в соответствие с Android и ПЗ.

## Критерий готовности

- Приложение архивируется через `xcodebuild` и даёт релизный артефакт.
- Поведение lock/unlock и статусных экранов соответствует Android-клиенту и серверному API.
