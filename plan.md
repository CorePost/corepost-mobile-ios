# Plan for corepost-mobile-ios

## Роль репозитория

iOS panic-клиент на Swift, функционально эквивалентный Android-приложению.

## Текущее состояние

- Собран SwiftUI-клиент с ручной настройкой серверного адреса и хранением секретов.
- Настроены реальная сборка через `xcodebuild`, архивирование и экспорт `.ipa`.
- Есть UI-demo материалы: скриншоты и видео с iOS Simulator.

## Что сделать

- Поддерживать parity по сценариям с Android-клиентом:
  - настройка подключения;
  - проверка статуса;
  - lock/unlock;
  - двухшаговое подтверждение;
  - обработка сетевых ошибок.
- Держать конфигурируемый API-слой без жёстко заданного адреса сервера.
- Хранить секреты в Keychain, а несекретные настройки отдельно.
- Удерживать безопасную сетевую политику:
  - debug-сборки могут использовать упрощённый режим для локальной разработки;
  - release-сборки должны работать с обычной ATS-политикой.
- Поддерживать UI tests, архивирование, экспорт `.ipa` и GitHub Releases.
- Синхронизировать тексты, branding и release-материалы с остальными клиентами CorePost.

## Критерий готовности

- Приложение архивируется через `xcodebuild` и даёт релизный артефакт.
- Поведение lock/unlock и статусных экранов соответствует Android-клиенту и серверному API.
