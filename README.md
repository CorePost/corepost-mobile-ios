corepost-mobile-ios это panic-клиент на SwiftUI для iPhone.
Приложение хранит server URL и секреты локально и позволяет их изменить или удалить.
Клиент поддерживает проверку связи, регистрацию demo-профиля, блокировку и разблокировку устройства.
Release IPA публикуется отдельно, а демонстрационные изображения и видео остаются в репозитории как артефакты.
Сетевой адрес не зашит в код и задаётся пользователем.
